# App icon

Ikon database diturunkan dari SVG orisinal Quethink di `docs/assets/icons/database.svg`. Warna indigo dan stroke putih mengikuti prototype. SVG di folder ini adalah sumber; PNG 1024 × 1024 merupakan hasil rasterisasi `rsvg-convert`, bukan gambar generatif atau aset pihak ketiga.

`adaptive-icon.png` memiliki latar transparan; Android memasangkan foreground ini dengan background indigo dari `app.json`.
