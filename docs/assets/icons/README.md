# Quethink SVG icons

24 original outline icons authored for Quethink on 2 November 2026. No third-party icon files or libraries were copied.

Every icon uses a 24 × 24 viewBox, currentColor, 1.75 stroke width, rounded joins and rounded caps. Use 20–24 dp in controls, with a 48 dp touch target. Keep the text label for navigation and meaningful actions. Decorative icons use aria-hidden in web SVG exports; give the containing control an accessible label in React Native.

These SVG files are source assets. Matching paths appear as editable vector nodes on FigCraft page **03 · Colors & SVG icons** and in the visual prototype. Set the stroke via the appropriate section color; do not use color alone to convey state.

Icons: home, book, calendar, forum, user, users, database, code, sparkles, download, qr, pin, check, lock, chart, edit, clock, arrow, chevron, play, archive, settings, mail, logout.
